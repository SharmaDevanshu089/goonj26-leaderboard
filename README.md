## ⚡ Key Highlights & Features

- **🏆 3D GSAP Animated Podium**: Staggered spring entrances for 1st (Gold), 2nd (Silver), and 3rd (Bronze) placed batches with real-time numerical score counter tickers and celebratory confetti physics.
- **✨ Dynamic Interactive Particle Canvas**: Zero-dependency HTML5 canvas particle system rendering ambient glowing celestial embers and constellation lines with interactive mouse repulsion.
- **🌓 Dual Dark & Light Themes**: 
  - *Deep Obsidian Void* with glassmorphic cards and gold/ultramarine glows.
  - *Crisp Alabaster* with crisp contrast and refined typography.
- **📜 Historical Tournament Archives**:
  - Browse past champions and event tallies (e.g., **Goonj '25** won by *Centurions*, **Goonj '24** won by *Apex Batch*).
- **🔒 Secure Admin Management GUI**:
  - Protected by authorized admin password:
    `I_AM_GONNA_GIVE_DEVANSHU_A_HUGE_PARTY`
  - Instant score modification with quick steppers (`+10`, `+25`, `+50`, `-10`).
  - Medal tally adjustments (🥇 Gold, 🥈 Silver, 🥉 Bronze).
  - Event result creator that logs completed matches and awards points.
  - **Automatic "Last Updated" timestamp generation** upon every change.
  - **Data Backup & Restore**: Export and Import full tournament states as `.json` files.
- **🚀 100% Vercel Deployable**: Includes `vercel.json` and optimized SPA routing.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Production Build
```bash
npm run build
```
Creates an optimized static bundle in `dist/`.

---

## 🌐 Deploy to Vercel

### Option A: Using Vercel CLI
```bash
npm install -g vercel
vercel
```

### Option B: Push to GitHub & Connect to Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com), click **Add New Project**, and import your repository.
3. Vercel will automatically detect Vite and configure the build settings.
